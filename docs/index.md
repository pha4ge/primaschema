# Primaschema

A toolkit for fetching, validating and interrogating tiled amplicon PCR primer
scheme definitions. Primaschema provides programmatic and command line access to
the [PHA4GE primer-schemes repository](https://github.com/pha4ge/primer-schemes),
a community repository of tiled amplicon primer schemes.

## Install

```shell
uv tool install primaschema
```

Alternatively `pipx install primaschema` or `python -m pip install primaschema`.
Python 3.12 or newer is required.

## Quick start

Download a scheme from the default index and validate it:

```shell
primaschema get example-scheme/400/v1.0.0 --output ./schemes
primaschema validate ./schemes/example-scheme/400/v1.0.0/info.json --checks core
```

## What a scheme looks like

Each scheme lives in a `name/amplicon_size/version` directory containing:

| File | Contents |
| --- | --- |
| `info.json` | Scheme metadata, validated against the schema |
| `primer.bed` | Primer coordinates against the reference |
| `reference.fasta` | The reference sequence the primers are defined against |
| `README.md` | Human-readable summary, regenerated by `rebuild` |

## Commands

| Command | Purpose |
| --- | --- |
| `create` | Create a new scheme from a `primer.bed` and `reference.fasta` |
| `validate` | Validate a single scheme, or every scheme under a directory (`--checks info`/`core`/`full`) |
| `rebuild` | Recompute checksums, regenerate the scheme README, normalise files |
| `index` | Build or update an `index.json` for a local schemes directory |
| `get` | Download schemes from an index |
| `modify` | Update contributors, vendors, target organisms, status, license, dates, generator |
| `flatten` / `unflatten` | Convert an `info.json` to and from a one-row CSV |
